# Результаты

Эта папка содержит результаты последнего запуска пайплайна.

- `hypotheses.csv` — список проверенных гипотез и краткие выводы;
- `summary.json` — машинно-читаемая сводка;
- `*_summary.csv` — таблицы по тональности, времени, форматам и авторам;
- `*.png` — графики для отчёта или презентации;
- `vk_with_sentiment.csv` — файл с метками тональности; локально он создаётся из-за большого размера, но не публикуется в Git.

Повторный запуск:

```bash
python -m src.analysis --input data/vk_with_sentiment.csv --output results
```
