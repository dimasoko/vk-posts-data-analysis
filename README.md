# Анализ постов из ВКонтакте

Проект по анализу данных: я проверяю, правда ли, что самые негативные посты появляются в понедельник вечером.

Проект собран как один воспроизводимый пайплайн для Google Colab:

`CSV из Kaggle -> очистка текста -> RuBERT -> признаки даты и вовлечённости -> гипотезы -> таблицы и графики`

## Главный результат

В выборке 16 438 постов от 89 авторов за период с 7 ноября 2011 года по 6 декабря 2024 года.

Исходная гипотеза **не подтверждается**:

- в понедельник вечером негативными были 21,2% постов;
- в остальное время — 24,1%;
- по доле негатива понедельник вечером занял 25-е место из 28 сочетаний дня и периода.

Это не означает, что понедельник всегда спокойнее. Это означает, что в данном датасете нет оснований считать понедельник вечером самым негативным временем.

## Дополнительные выводы

1. Негативные посты обычно получают меньше реакций: медиана вовлечённости — 1 730 против 1 974 у нейтральных и положительных постов.
2. Длина текста связана с тональностью: медиана — 12 слов у негативных постов, 7 у нейтральных и 9 у положительных.
3. Формат поста связан с распределением тональности. Связь есть, но она умеренная: формат сам по себе не объясняет настроение поста.
4. Авторы заметно различаются: среди авторов с 30 и более постами доля негатива меняется от 7,1% до 97,4%.
5. Главный вывод нельзя трактовать как причинный: данные показывают совместное изменение признаков, но не объясняют, почему оно возникло.

## Структура

- `notebooks/01_vk_full_analysis_colab.ipynb` — единый ноутбук для запуска в Google Colab: от загрузки исходного CSV до результатов.
- `src/analysis.py` — локальная версия аналитического этапа для файла, где уже есть `sent_label`.
- `data/README.md` — где взять данные и какие файлы нужны.
- `results/` — актуальные таблицы, графики и `summary.json`.

## Запуск в Google Colab

1. Откройте `notebooks/01_vk_full_analysis_colab.ipynb` в Colab.
2. Загрузите исходный `vk_filtered_posts_metadata.csv` с Kaggle.
3. Выполните ячейки сверху вниз.
4. Скачайте папку `results` и файл `vk_with_sentiment.csv`.

Если загрузить файл, где уже есть колонка `sent_label`, модель повторно запускаться не будет.

## Локальный запуск

```bash
pip install -r requirements.txt
python -m src.analysis --input data/vk_with_sentiment.csv --output results
```

## Ограничения

- тональность определяет готовая модель, а не ручная разметка;
- в данных не указан часовой пояс;
- выборка не описывает всех пользователей VK;
- статистическая связь не доказывает причинность;
- для авторов используется описательное сравнение, потому что у них разное число постов.
